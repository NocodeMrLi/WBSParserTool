项目名称：需求文档自动拆解工具

一、项目背景
需要构建一个 Windows 本地小工具，用于将复杂需求文档拆解成可执行的 WBS 和具体任务清单。

二、核心需求
1. 支持用户上传 PDF、DOCX、TXT 格式的需求文档。
2. 支持本地解析，不联网即可生成基础 WBS 和任务清单。
3. 支持在线解析，用户可以自行配置 API Base URL、API Key 和模型名称。
4. 点击解析后需要显示解析进度条和当前状态。
5. 解析完成后生成工作分解结构 Word 文档和任务清单 Excel 文件。
6. 用户选择交付文件后，可以点击存储并保存到本地目标位置。

三、约束
工具窗口保持传统 Windows 风格，只需要最小化和关闭，不需要最大化。
